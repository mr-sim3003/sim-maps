🔩 Уровень 6: URLPattern (готовый механизм)
🏷️ URLPattern
📝 pattern
Шаблон URL
'articles/<int:id>/'
Хранит скомпилированный шаблон
Умеет сравнивать через .match()
📖 callback
Указатель на view
views.article_detail
Функция или класс
🏷️ name
Имя маршрута
'article_detail'
Для reverse() и {% url %}
⚙️ resolve(path)
Метод проверки
match = self.pattern.match(path)
if match: return ResolverMatch(...)
return None
📦 ResolverMatch
Результат (если совпало)
📖 .func — view
🔢 .kwargs — параметры
🏷️ .url_name — имя
